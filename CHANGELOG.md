## 0.6.0 (2026-11-20)

Release 5 simplifies ngkit (E19) without changing its public imports or wire
formats, apart from the break below, and adds loading timings (F6.1).

### 🚀 Features

- `@rn-forge/ng/core`: `loadingTimings(loading, options?)` turns a loading
  signal into a `show` signal that appears only after `delay` (default 300 ms)
  and, with `minDuration` (default 0), stays up at least that long.
  `RNF_LOADING_TIMINGS` sets the defaults.
- `@rn-forge/ng-bootstrap/auth`: `UserSettingsService.registerChangeListener`
  returns a disposer, and `UserSettingsService.hasStoredSetting(key)` reports
  whether a setting is explicitly stored.

### 🩹 Fixes

- `@rn-forge/ng/crud`: a CRUD form submission keeps `0` and `false`, and sends
  arrays, dates and objects without an `id` unchanged instead of dropping
  them.
- `@rn-forge/ng-bootstrap/shell`: the header uses the user's saved navbar colour
  over `config.navbarColor`.

### ⚠️ Breaking Changes

- `@rn-forge/ng-bootstrap/form`: `MultiTypeaheadFieldComponent` no longer
  exposes `onChange`, `onTouched`, `writeValue`, `registerOnChange`,
  `registerOnTouched` or `setDisabledState`. They were never connected to
  Angular forms; the field now reads and writes its control in the parent
  `FormGroup`.

## 0.5.0 (2026-11-18)

Release 4 adds the session client and its Bootstrap auth UI, and a new package,
`@rn-forge/ng-plugin`.

### 🚀 Features

- `@rn-forge/ng/auth`: a session client. `provideRnForgeAuth` configures it, and
  `authGuard` and `permissionGuard` guard routes.
- `@rn-forge/ng-bootstrap/auth`: Bootstrap auth UI on the session client,
  accepted against a FastAPI backend.
- `@rn-forge/ng-plugin`: Nx generators (`setup`, `add-bootstrap-table`,
  `configure-theme`, `scaffold-component`, `create-library`,
  `configure-testing`) that set up Angular apps and libraries for the rn-forge
  packages. It releases with the group.

### ⚠️ Breaking Changes

- `@rn-forge/ng/auth`: the configuration (`provideRnForgeAuthConfig`,
  `RnForgeAuthConfig`, `RN_FORGE_AUTH_CONFIG_TOKEN`) is removed; use
  `provideRnForgeAuth`. The credentials types and services (`LoginResponse`,
  `UserProfile`, `JwtCredentials`, `JwtToken`, the `refreshToken` hook,
  `disableAuth`) are removed. The guard (`authRouteGuard`, `ignoreAppRoutes`)
  is removed; use `authGuard` and `permissionGuard`. The `jwt-decode`
  dependency is removed.
- `@rn-forge/ng-bootstrap/auth`: the whole surface is replaced, including
  `AuthComponent`'s login and logout modes and `UserComponent`'s use of
  `UserProfile`.

## 0.4.0 (2026-11-15)

Release 3 adopts kiln's `node-lib` archetype (E17) and settles the E5 wire
contract (F5.1, ADR-0006). There are no breaking changes to the libraries' code;
the packaging changes are:

- Internal peers publish as a caret range on the released version:
  `@rn-forge/ng-bootstrap`'s peer on `@rn-forge/ng` is `^0.4.0` in the
  tarball.
- `@rn-forge/ng-bootstrap` declares its `./assets/*` export in source; the
  published entry is now the condition object
  `{ "sass": "./assets/*.scss", "default": "./assets/*" }`, where it was a
  string. `default` is the old target, so every import that resolved before
  resolves to the same file.
- CI, the task surface, the docs site and the release job are generated by kiln.
  The release job now tags `main` on a push and attaches the tarballs of `ng`,
  `ng-bootstrap` and `ng-tailwind` to a GitHub Release.

## 0.2.0 (2026-10-14)

### 🩹 Fixes

- ⚠️ **release:** apply the version bump as given below 1.0.0
  ([76f8901](https://github.com/rn-forge/ngkit/commit/76f8901))

### ⚠️ Breaking Changes

- **release:** apply the version bump as given below 1.0.0
  ([76f8901](https://github.com/rn-forge/ngkit/commit/76f8901)) Release 1
  changes the public API.
    - @rn-forge/ng/http and /http/crud are removed (AbstractHTTPService,
      BackendService, HttpUtil, DownloadResponse, apiBasePath); use HttpClient.
    - AuthBackendService requires backend.baseUrl when used.
    - FormUtil validators run on pristine values; DATE_RANGE(start?, end?) is a
      group validator; the old DATE_RANGE(formGroup, …) form is removed.
    - ObjectUtil.diff compares scalars strictly and arrays and dates structurally.
    - CrudDataSource and its types moved from @rn-forge/ng-bootstrap/crud to
      @rn-forge/ng/crud and changed shape (AIP-158 lists; get, delete and
      Versioned added; count/next/previous/results, BulkDeleteResponse,
      UploadResponse and upload removed).
    - The ng-bootstrap/crud mode 'upload' is now 'import', and 'download' is
      removed (export is a direct GET).
    - The permission keys .upload/.download are now .import/.export.
    - The CRUD table renders one server page with token paging; there are no
      numbered pages.
