# ADR-0002: Package boundaries are one-way; presentation libraries only render

**Status:** accepted (2026-09-23) · **Scope:** every ngkit package and secondary entry point

## Decision

`ng` has no UI and no presentation dependencies. `ng-bootstrap` depends on `ng`, never the reverse. A future `ng-tailwind` must not import `ng-bootstrap`. State and behavior shared between presentation libraries live in `ng`. Angular and RxJS are peers. Implementation libraries are `dependencies`, declared in `allowedNonPeerDependencies`. Secondary entry points can't declare their own peers, so a heavy, situational dependency goes behind an optional peer.

Presentation-free state and behavior go into `ng`, so a presentation library only renders.

The supported Angular range is the tested matrix: 22.0.6 and 22.1.7, each with zone and zoneless change detection. The peers use a caret range (`^22.0.6`), because ngkit has no external consumers yet; `ng-bootstrap`'s `@angular/cdk` peer stays at `^22.0.4`, which already spans the tested versions. `devDependencies` stay at the workspace's Angular version (`^22.1.7`), so the peer floor is not the version the workspace builds with. Bump a peer floor only on purpose, together with the matrix.

## Consequences

- No lint enforces the direction between entry points and packages yet (`@nx/enforce-module-boundaries` has no tag constraints), so review does.
- `lodash-es`, `build-url-ts` and `jwt-decode` are `dependencies` of `ng`, not mandatory peers, so a storage or date consumer manages no auth implementation dependencies. `@angular/forms` and `@angular/router` stay mandatory peers of the whole package. `ng-bootstrap` keeps `lodash-es` as a peer, because several of its components use it directly; it is not an implementation detail of one entry point.
- A peer range wider than the matrix would claim support that nothing tests.
- Raising a peer floor to the workspace's version by accident drops the 22.0 cells of the matrix: `ng:verify-consumer` fails with `ERESOLVE` on 22.0.6.

## Alternatives considered

- **A hand-built `>=22.0.6 <23` bound.** It claims an upper bound nobody tested; the caret range plus the matrix says the same thing honestly.
- **Leaving implementation libraries as mandatory peers.** Every consumer would have to install libraries used by one entry point.
