# F8.4 — Consumer and accessibility acceptance

**Status:** elaborating · **Owner:** ngkit · **Epic:** [E8](index.md)

**Depends on:** [F8.1](F8.1-package.md), [F8.2](F8.2-css-contract.md), [F8.3](F8.3-button.md).

Proof from the packed tarball that a consumer with Tailwind and a consumer without it both render the package, and proof in a browser that the token defaults and the button meet WCAG AA in both schemes.

## Design

- **`ng-tailwind:verify-consumer`.** It extends `tools/scripts/verify-consumer.mjs` with an `ng-tailwind` matrix row ([Adding a publishable library](../../../guides/development.md#adding-a-publishable-library), step 7), installing the packed tarball by `file:` into throwaway applications on the existing Angular matrix (22.0.6 and 22.1.7, zone and zoneless). Two fixtures:
  - **Plain.** A standalone application whose global stylesheet imports `tokens.css` only, with a `<button rnfButton>` and an `<a rnfButton>`. No Tailwind is installed.
  - **Tailwind.** The same application with `tailwindcss` 4 and `@tailwindcss/postcss`, importing the sheets in the order [F8.2](F8.2-css-contract.md#tailwindcss-opt-in) gives, plus `base.css`, and a template that also uses `bg-surface-1 text-muted rounded-control`, `bg-slate-500`, and `w-full` on a button.
- **Browser checks** run in Playwright, ngkit's e2e runner, in an `ng-tailwind-e2e` project: over the built Storybook for the token and button stories, and over the built Tailwind fixture for the cascade. Text contrast uses axe-core's `color-contrast` rule through `@axe-core/playwright` (a new dev dependency, approved when the feature is built); the 3:1 non-text checks compute the WCAG 2.1 ratio from `getComputedStyle` values. Each runs with `colorScheme` emulated as `light` and as `dark`, and the button stories once more with `forcedColors: 'active'`.
- **A tokens story** renders each text token on each of `surface-0`, `-1` and `-2`, each tone's text on its wash, and `border-strong` and `focus` swatches, so the browser checks read real computed values.

## Stories

### S8.4.1 — Consumers build from the tarball

**Status:** elaborating

**Acceptance:**

- `pnpm nx run ng-tailwind:verify-consumer` installs the packed tarball into both fixtures on all four matrix cells, and each `ng build` succeeds.
- The plain fixture's built CSS contains `--rnf-surface-0` and the button's `rnf` layer rules, and its `node_modules` has no `tailwindcss`.
- The Tailwind fixture's built CSS has rules for `bg-surface-1`, `text-muted`, `rounded-control` and `w-full`, the first three resolving to `var(--rnf-*)`, and none for `bg-slate-500`.

### S8.4.2 — WCAG AA in both schemes

**Status:** elaborating

**Acceptance:**

- With `colorScheme: 'light'` and with `'dark'`, axe reports no `color-contrast` violation on the tokens story or any button story.
- On the tokens story, `border-strong` and `focus` reach 3:1 against `surface-0`, `-1` and `-2` in both schemes.
- Setting `color-scheme: dark` on one container of a light page switches that container's computed `--rnf-surface-0` and the container's button colours, and nothing outside it.
- With `forcedColors: 'active'`, every button variant has a non-transparent computed border colour, and a focused button a visible outline.
- With `reducedMotion: 'reduce'`, a button's computed `transition-duration` is at most `0.01s`.
- Keyboard: Tab reaches a button and an enabled link button and skips a disabled link button; Enter and Space activate a button; Enter follows a link.

### S8.4.3 — Application CSS wins the cascade

**Status:** elaborating

**Acceptance:**

- In the Tailwind fixture, a button with class `w-full` inside a 400 px container has a computed width of 400 px.
- An unlayered application rule `:root { --rnf-accent: <colour> }` placed before the package's `tokens.css` import still changes a `primary` button's computed background.

## Acceptance

```bash
set -euo pipefail
pnpm nx run ng-tailwind:verify-consumer                       # S8.4.1
pnpm nx run-many -t build-storybook -p ng-tailwind            # S8.4.2
pnpm nx run ng-tailwind-e2e:e2e                               # S8.4.2, S8.4.3
```
