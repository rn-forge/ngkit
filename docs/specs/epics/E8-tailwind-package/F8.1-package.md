# F8.1 — The package and its release wiring

**Status:** done · **Implemented:** 2026-10-24 · **Owner:** ngkit · **Epic:** [E8](index.md)

**Depends on:** none.

`libs/ng-tailwind`, published as `@rn-forge/ng-tailwind` in the fixed release group, with its CSS files exported beside its entry point. This feature delivers the package's shape; the CSS is [F8.2](F8.2-css-contract.md) and the first component is [F8.3](F8.3-button.md).

## Design

- **Scaffold.** Through the Nx generator (`pnpm nx g @nx/angular:lib`, `--publishable`, import path `@rn-forge/ng-tailwind`; invoke the `nx-generate` skill and read `--help` first). One primary entry point; a secondary entry point is added only when a component family brings a heavy, situational dependency ([ADR-0002](../../../adr/ADR-0002.md)).
- **Release.** The checklist in [Adding a publishable library](../../../guides/development.md#adding-a-publishable-library): `package.json` metadata as `ng` and `ng-bootstrap` have it, the `publishable` tag (which puts it in the [ADR-0003](../../../adr/ADR-0003.md) fixed group, `preVersionCommand`, the release workflow and CI's package job without editing them), the `manifestRootsToUpdate` pair, `pack`, `verify-dist`, and `nx-release-publish` with `dryRun: true`. `nx.json` does not change. These are repository configuration and are reviewed together under the repository's approval rules.
- **Peers.** Only what the code imports. F8.3's Button needs `@angular/core` alone, so that is the first peer (`^22.0.6`, the ADR-0002 range). `@angular/cdk` and `@angular/aria` become peers with the first component that uses them, not before; `@nx/dependency-checks` flags an unused one. `@rn-forge/ng` becomes a same-release peer only when a component uses shared behaviour from it. `tailwindcss` (`^4`) is an optional peer (`peerDependenciesMeta`), because only the bridge file reads it.
- **CSS files.** `tokens.css`, `base.css` and `tailwind.css` ship as package assets, exported as `./tokens.css`, `./base.css` and `./tailwind.css` through the existing `patch-package-exports` pattern, as `ng-bootstrap` exports `./assets/*`. `sideEffects` lists `*.css` only.
- **Docs.** A `compodoc` target writing to `dist/compodoc/ng-tailwind` and a `build-storybook` target writing to `dist/storybook/ng-tailwind`, so the [docs site](../../../architecture/release-pipeline.md#docs-site) picks both up. Storybook builds from the library's own configuration with the token sheet as its only global style, not from `ng-demo`'s build, whose Bootstrap CSS would hide a missing style. Bootstrap's docs are not changed.
- **Rows.** The Projects table in `README.md` and [Workspace](../../../architecture/workspace.md) gain the package; `libs/ng-tailwind/README.md` shows the stylesheet imports for a plain consumer and for a Tailwind consumer ([F8.2](F8.2-css-contract.md#design)).

## Stories

### S8.1.1 — Scaffold, metadata and peers

**Status:** done (2026-10-24)

**Acceptance:**

- `pnpm nx show project ng-tailwind --json` lists the `publishable` tag and the targets `build`, `lint`, `test`, `pack`, `verify-dist`, `nx-release-publish`, `compodoc` and `build-storybook`.
- `libs/ng-tailwind/package.json` has `description`, `license`, `repository` (with `directory`), `publishConfig.access: "public"`, peers `@angular/core` and an optional `tailwindcss`, and no dependency on `@rn-forge/ng-bootstrap`.
- `release.version.manifestRootsToUpdate` is the pair `{projectRoot}` and `{ "path": "dist/{projectRoot}", "preserveLocalDependencyProtocols": false }`; `nx-release-publish` has `dryRun: true`.
- Nothing under `libs/ng-tailwind` imports `@rn-forge/ng-bootstrap`, `bootstrap` or `jquery`.

### S8.1.2 — CSS exports and the packed artifact

**Status:** done (2026-10-24)

**Acceptance:**

- After `pnpm nx run ng-tailwind:pack`, `dist/tarballs/rn-forge-ng-tailwind-<version>.tgz` exists and its `package.json` `exports` map has `./tokens.css`, `./base.css` and `./tailwind.css`, each resolving to a file in the tarball, and no `workspace:*` anywhere.
- `pnpm nx run ng-tailwind:verify-dist` passes.

### S8.1.3 — Docs targets and rows

**Status:** done (2026-10-24)

**Acceptance:**

- `pnpm nx run ng-tailwind:compodoc` writes `dist/compodoc/ng-tailwind/index.html`; `pnpm nx run ng-tailwind:build-storybook` writes `dist/storybook/ng-tailwind/index.html`, and the built preview loads no Bootstrap stylesheet.
- `README.md` and [Workspace](../../../architecture/workspace.md) list `ng-tailwind`; `libs/ng-tailwind/README.md` shows both consumer setups.

## Acceptance

```bash
set -euo pipefail
absent() { local rc=0; rg -q --hidden --glob '!.git' "$@" </dev/null || rc=$?; [ "$rc" -eq 1 ]; }
pnpm nx show project ng-tailwind --json | jq -e '.tags | index("publishable")'          # S8.1.1
jq -e '.publishConfig.access == "public" and .peerDependencies["@angular/core"] and .peerDependenciesMeta.tailwindcss.optional' libs/ng-tailwind/package.json  # S8.1.1
absent -e '@rn-forge/ng-bootstrap' -e "from 'jquery'" -e "from 'bootstrap'" libs/ng-tailwind  # S8.1.1
pnpm nx run-many -t lint test build -p ng-tailwind                                     # S8.1.1
pnpm nx run ng-tailwind:pack                                                           # S8.1.2
tgz=$(ls dist/tarballs/rn-forge-ng-tailwind-*.tgz)
tar -xOf "$tgz" package/package.json | jq -e '.exports["./tokens.css"] and .exports["./base.css"] and .exports["./tailwind.css"]'  # S8.1.2
absent -z -e 'workspace:' "$tgz"                                                       # S8.1.2
pnpm nx run ng-tailwind:verify-dist                                                    # S8.1.2
pnpm nx run-many -t compodoc build-storybook -p ng-tailwind                            # S8.1.3
test -f dist/compodoc/ng-tailwind/index.html && test -f dist/storybook/ng-tailwind/index.html  # S8.1.3
rg -q 'ng-tailwind' README.md docs/architecture/workspace.md                           # S8.1.3
```

Not scriptable: the owner reviews the `project.json` and `package.json` release settings together, as for any new publishable library.
