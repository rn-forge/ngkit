# F8.3 — `rnfButton`

**Status:** elaborating · **Owner:** ngkit · **Epic:** [E8](index.md)

**Depends on:** [F8.2](F8.2-css-contract.md).

The package's first component, moved here from [E9](../E9-presentation-primitives/index.md#further-families) (item 8). It is the smallest component that exercises every rule of the CSS contract (attribute selector on a native element, tokens only, variants, focus, disabled and busy states, forced colours), so the packaging and consumer checks have something real to render. Every surveyed application hand-rolled one: one as a wrapper component holding a `<button>` with `routerLink` set on the wrapper, which navigates from a button and doubles `type` and `disabled`; the others as global classes used at more than 50 call sites.

## Design

```ts
@Component({
  selector: 'button[rnfButton], a[rnfButton]',
  host: {
    class: 'rnf-button',
    '[attr.data-variant]': 'variant()',
    '[attr.data-shape]': 'shape()',
    '[attr.data-size]': 'size()',
    '[attr.aria-busy]': 'busy() || null',
    '[attr.aria-disabled]': 'isAnchor && (disabled() || busy()) || null',
    '[attr.disabled]': '!isAnchor && (disabled() || busy()) || null',
    '[attr.tabindex]': 'isAnchor && (disabled() || busy()) ? -1 : null',
  },
  template: '<ng-content />',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class RnfButton {
  readonly variant = input<'secondary' | 'primary' | 'accent' | 'ghost' | 'danger'>('secondary');
  readonly shape = input<'default' | 'pill'>('default');
  readonly size = input<'md' | 'sm'>('md');
  readonly disabled = input(false, { transform: booleanAttribute });
  readonly busy = input(false, { transform: booleanAttribute });
}
```

- **Native semantics.** A `<button>` stays a button and keeps its own `type`; an `<a>` stays a link, so `routerLink`, query parameters and fragments work unchanged. A disabled or busy anchor gets `aria-disabled="true"`, leaves the tab order and swallows clicks; a disabled or busy button gets the native `disabled` attribute.
- **Variants.** `secondary` (the default: `surface-1` fill, `border-strong` edge), `primary` (`accent` fill, `on-accent` text), `accent` (`accent-muted` fill, `accent` text), `ghost` (no fill or edge until hover) and `danger` (`danger` text and edge, wash on hover). `shape: 'pill'` uses `radius-pill`; `size` picks `control-sm` or `control-md` and `text-xs` or `text-sm`. Projected icons are the application's; the button only spaces them.
- **States.** Hover and active from tokens; `:focus-visible` uses `focus`. Under `forced-colors: active` the edge is a transparent border that the system colours, so every variant keeps a visible boundary. Transitions use `duration-fast` and stop under `prefers-reduced-motion`.
- **Styles.** One emulated-encapsulation stylesheet inside `@layer rnf`, no colour literal, no `::ng-deep` or `:host-context` ([E8 prior art](index.md#prior-art-an-applications-ui-folder)).

E9's item 8 listed `primary | ghost | accent | danger`; `secondary` is added as the default because a button with no variant needs a neutral look, which all three applications defined; `size` and `busy` are added because two applications needed a compact size and a pending state.

## Stories

### S8.3.1 — The component

**Status:** elaborating

**Acceptance:**

- Specs (Vitest, TestBed) host the directive on `<button>` and on `<a routerLink>`: the host keeps its tag, gets class `rnf-button` and `data-variant`, `data-shape` and `data-size` matching the inputs, defaulting to `secondary`, `default` and `md`.
- `disabled` on a button sets the native `disabled`; on an anchor it sets `aria-disabled="true"` and `tabindex="-1"`, and a click on it neither navigates nor reaches a `(click)` handler. `busy` does the same and sets `aria-busy="true"`.
- A `<button rnfButton type="submit">` inside a form submits it.
- `RnfButton` is exported from `@rn-forge/ng-tailwind`; its stylesheet reads no custom property outside `--rnf-*` and contains no colour literal.
- Storybook stories cover every variant in each size and shape, disabled and busy, as a button and as a link.
