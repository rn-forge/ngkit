# F5.4 — Acceptance against a session backend

**Status:** elaborating · **Owner:** ngkit · **Epic:** [E5](index.md) · **Release:** [Release 3](../../../releases/release-3/index.md)

**Depends on:** [F5.2](F5.2-auth-wrapper.md), [F5.3](F5.3-bootstrap-auth-ui.md), and a released server library, pinned by tag in the fixture's manifest, that serves the routes in [Design](design.md) with a development provider. Until such a release exists this feature cannot start.

`ng-demo`'s e2e suite signs in to the [F4.3](../E4-standard-resource-screen/F4.3-wire-acceptance.md) backend fixture through its development provider, offline, and exercises the session client end to end. The fixture grants its fixture accounts different permissions on the products resource.

## Stories

### S5.4.1 — Fixture auth

**Status:** planned

**Acceptance:** the backend fixture serves the auth routes through the pinned library, with a development provider and two fixture accounts: one with every `products.*` permission and one with `products.list` and `products.read` only. Unsafe requests without the XSRF header are refused.

### S5.4.2 — Acceptance run

**Status:** planned

**Acceptance:** with `ng-demo` served against the fixture, the e2e suite shows:

- an anonymous visit to the products screen goes through the development provider and returns to the products screen;
- the read-only account sees no create, edit or delete actions, and a direct `PATCH` it makes is answered `403` and lands on the forbidden page while still signed in;
- after the fixture ends the session, the next request starts a login, and a session cookie the browser never stores ends at the error page with `session_not_established` instead of looping;
- logout returns to the login page and `/auth/session` then answers `401`.

## Acceptance

- Each story's acceptance holds (S5.4.1, S5.4.2).
- `pnpm nx e2e ng-demo-e2e` passes on both CI paths.
- An optional CI job runs the same suite through a local Keycloak container as an OIDC provider; it is not required for the feature to be done.
