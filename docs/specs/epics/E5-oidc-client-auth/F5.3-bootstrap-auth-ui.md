# F5.3 — Bootstrap auth UI

**Status:** elaborating · **Owner:** ngkit · **Epic:** [E5](index.md)

**Depends on:** [F5.2](F5.2-auth-wrapper.md).

`ng-bootstrap/auth` follows the wrapper: the identity provider owns the login page, so ngkit keeps only a signed-in user menu and a forbidden page. User, group and permission screens are [E4](../E4-standard-resource-screen/index.md) resource screens, or the identity provider's admin.
