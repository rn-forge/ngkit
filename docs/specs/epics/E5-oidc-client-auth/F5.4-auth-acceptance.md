# F5.4 — Acceptance against an identity provider

**Status:** elaborating · **Owner:** ngkit · **Epic:** [E5](index.md)

**Depends on:** [F5.2](F5.2-auth-wrapper.md), and the same kind of pinned server library as [F4.3](../E4-standard-resource-screen/F4.3-wire-acceptance.md). Reuse F4.3's fixture if its stack can verify bearer tokens.

`ng-demo` against a local Keycloak container (code + PKCE) calling a backend fixture that verifies bearer tokens through OIDC discovery and JWKS: a missing token is 401 with a challenge, a missing scope is 403 without one, and the UI hides actions without the scope.
