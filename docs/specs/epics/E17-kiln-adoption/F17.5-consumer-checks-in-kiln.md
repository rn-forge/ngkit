kiln's
[F9.4](https://github.com/rn-forge/kiln/blob/main/docs/specs/epics/E9-node-archetypes/F9.4-node-helpers-in-kiln-devops.md)
moves the node CI helpers into `kiln-devops`: `tools/ci/*.mjs` stops being
rendered, `pack` and `verify-dist` call `task ci:dist:*`, and a library's peer
matrix lives in its own `package.json`. This feature takes ngkit onto that. The
matrix and the Angular app builds in `tools/scripts/verify-consumer.mjs` move to
`workspace-ci.consumer` tables and two small hook files, and the script is
deleted.

tooling after `patch-package-exports.mjs` (F17.4). Both features edit
`libs/*/project.json` and `nx.json`, so F17.5 is built after F17.4. It is
cutover-adjacent, so it sits in Release 3 with the rest of E17.

**What kiln does (read at `6da1438`, `src/rn_forge/kiln/devops/consumer.py` and
`cli.py:110-114,296-297`).**

- `kiln-devops consumer <project-root> [--cell <name>]`, run from the workspace
  root, reads `<project-root>/package.json`, finds
  `dist/tarballs/<name with '@' dropped and '/' as '-'>-<version>.tgz`, and
  per cell writes `dist/consumer-fixtures/<tarball stem>/<cell>/` (here
  `dist/consumer-fixtures/rn-forge-ng-0.3.0/22.1-zone/`), with a
  `package.json` (`name` `consumer-<cell>`, `type: module`, the cell's merged
  `dependencies` plus the `file:` tarball),
  `npm install --no-audit --no-fund`, the `workspace:` check, a generated
  `smoke.mjs` (`import "<preload>";` lines in order, then `import * as` for
  every JavaScript subpath of the installed `exports`, failing on an empty
  namespace) run with `node smoke.mjs`, and last
  `node <workspace root>/<hook> <fixture dir> <cell name>` with the fixture as
  the working directory. Cell names must match `[A-Za-z0-9._-]+`.
- A failing cell does not stop the rest. The summary is
  `consumer: <n> of <m> cells failed: <cells>` (exit 1) or
  `consumer: <m> cells passed` (exit 0). A missing tarball exits 1 before any
  `npm` call; an unknown `--cell` exits 2 and lists the declared cells.
- `dist-resolve` drops `workspace-ci` from the dist manifest (`pack` is where
  this happens), so the matrix is not published.
- `nx.json` is not rewritten by kiln when it exists. kiln's values for `pack`,
  `verify-dist` and `verify-consumer` are in
  `modules/node/scaffold.py:_RELEASE_TARGET_DEFAULTS` and are what the
  reference repository gets.

**Three differences from the script, all intended.**

- **The fixture path gains the version.** The e2e fixture is now
  `dist/consumer-fixtures/rn-forge-ng-tailwind-<version>/tailwind-22.1-zoneless/`,
  where it was `ng-tailwind-tailwind-angular-22.1-zoneless/`. S17.5.3
  computes the version in `playwright.config.mts` from
  `libs/ng-tailwind/package.json`.
- **ng-tailwind also gets kiln's Node import smoke.** The script only built the
  apps. kiln imports every JavaScript entry point of the installed package
  first (proved in 3 above), with `@angular/compiler` preloaded for the
  partial declarations.
- **A hook cannot import the fixture's packages directly.**
  `node <workspace>/tools/consumer/<hook>` resolves bare imports from the
  workspace's `node_modules`, not the fixture's. `ng-smoke.mjs` therefore
  writes `roundtrip.mjs` into the fixture and runs it there, as the script did
  with `smoke.mjs`.

    ```js
    #!/usr/bin/env node
    /**
     * `kiln-devops consumer` hook for @rn-forge/ng. Run as
     * `node tools/consumer/ng-smoke.mjs <fixture-dir> <cell>` after kiln has installed
     * the packed tarball into the cell's fixture and imported every entry point.
     * Adds the LocalStorageService round trip through DI. The cell name is
     * `<angular>-<zone|zoneless>`.
     */
    import { execFileSync } from 'node:child_process';
    import { writeFileSync } from 'node:fs';
    import { join } from 'node:path';

    const [fixture, cell] = process.argv.slice(2);
    const cellMatch = /^\d+\.\d+-(zone|zoneless)$/.exec(cell ?? '');
    if (!fixture || !cellMatch) {
      console.error('Usage: ng-smoke.mjs <fixture-dir> <angular>-<zone|zoneless>');
      process.exit(2);
    }
    const changeDetectionMode = cellMatch[1];

    // The script runs from the fixture directory, so `@angular/core` and
    // `@rn-forge/ng` resolve from the fixture's node_modules, not this workspace's.

    // A real consumer app builds through the Angular CLI, which runs the linker
    // so libraries ship fully AOT-compiled. This bare Node smoke test has no
    // bundler in front of it, so classes with partial compilation (e.g.
    // @angular/common's PlatformLocation, referenced transitively by
    // RouteService) need the JIT compiler as a fallback.
    ```

## Considered and rejected

- **Keep the script and call it from the `verify-consumer` targets.** The point
  of F9.4 is that a fix to the install, matrix loop and import smoke arrives
  with the kiln pin. ngkit would keep a second copy of them.
- **Hand-edit `nx.json`'s `pack`, `verify-dist` and `verify-consumer`.** kiln
  never rewrites an existing `nx.json`, so a hand copy would drift from the
  reference on the next bump. The cutover takes the reference's file whole and
  re-applies only ngkit's own differences.
- **One hook for both libraries.** The two checks share nothing: one is a Node
  round trip, the other builds Angular applications and asserts on their CSS.
- **Declare only the `22.1` cells, or drop zone from `ng-tailwind`.** Today's
  matrix is four cells per library, and `ng`'s peer floor is `^22.0.6`; fewer
  cells would stop testing it.
- **Serve the e2e fixture from a fixed path by copying it.** A copy step in the
  hook would exist only for Playwright. Reading the version in
  `playwright.config.mts` is one expression.
