# F17.2 — Cut over onto kiln

**Status:** planned · **Owner:** ngkit · **Epic:** [E17](index.md) · **Release:** [Release 3](../../../releases/release-3/index.md)

**Depends on:** kiln's release-1 tag exists, observed from outside kiln (below). S17.2.1 comes first; [F17.1](F17.1-docs-model.md) follows it; S17.2.2 to S17.2.5 wait on F17.1.

ngkit adopts kiln's `node-lib` archetype in place: `kiln init`, then kiln's generated workflows, setup action, `tools/ci` helpers and Nx Cloud agent template replace ngkit's copies of the same files, and the owner reviews the applied change against the differences the owner approved. The libraries, `nx.json`, project targets and tags are not touched.

## Stories

### S17.2.1 — Prepare and run `kiln init`

**Status:** planned · **Depends on:** kiln's release-1 tag

**Build:**

- Entry criteria above, observed. Create branch `feature/kiln-adoption` from `main` in the checkout directory named `ngkit`, with a clean tree (`init` refuses a dirty one).
- Install the tools a developer needs once: `go-task` and `uv` (`brew install go-task uv`). The generated tasks run kiln with `uvx`; it is not a dependency.
- Do not add a root `pyproject.toml` or `mkdocs.yml` by hand: `init` creates both (kiln S9.1.15). The `pyproject.toml` has no package. Its `dev` group holds the generated tasks' tools and its `docs` group the six docs packages, which `mdformat` needs so that it does not collapse ngkit's tables.
- Preview, writing nothing: `uv run --project <kiln> kiln init --archetype node-lib --docs mkdocs --dry-run`. The plan matches the trial's: 19 managed conflicts, 9 managed creates, 2 block inserts and the seeded skips. The seeded creates are the trial's five plus `pyproject.toml` and `mkdocs.yml`. Read each conflicting file now and list anything it holds that kiln's will not: from the trial, `.editorconfig`'s `[*.md] max_line_length = off`, and the comments in `sonar-project.properties` that explain the exclusions (S17.2.2 keeps those). A plan with a conflict the trial did not show is investigated before `init` runs.
- Run `uv run --project <kiln> kiln init --archetype node-lib --docs mkdocs --yes --force`. `--force` backs each conflicting file up to `.rn-forge/kiln/backups/<UTC timestamp>/`. Commit its change alone, with `uv.lock`: `chore: kiln init as node-lib`. Do not edit any generated file.
- Run `task setup` (installs the pnpm workspace and the docs tooling).

**Acceptance:**

- `.rn-forge/kiln/config.toml` has `archetype = "node-lib"` and `profile = "mkdocs"`, and `.rn-forge/kiln/state.json` exists.
- `kiln init`'s own closing check exited 0.
- `git diff main --stat -- libs apps nx.json project.json package.json pnpm-workspace.yaml .nvmrc tools/scripts` is empty: `init` touched none of what ngkit keeps.
- `.rn-forge/kiln/backups/` holds the replaced files.
