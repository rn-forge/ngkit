ngkit adopts kiln's `node-lib` archetype in place. kiln's files are overlaid
from a `kiln new` reference; kiln's generated workflows, setup action, Nx Cloud
agent template and `ci:*` tasks then replace ngkit's copies; and the owner
reviews the applied change against the verdicts on this page. ngkit's libraries,
apps, manifests and lock file are not touched. This page holds the whole
cutover, so it can be rerun from the page alone, many times, before it merges:
the `kiln new` input and every step are scripts in
[`F17.2-cutover/`](F17.2-cutover/), and the page carries the reasons, the
verdicts and a "Run it" list per story.
