# S17.5.1 — Take kiln's `ci:dist:*` and `ci:consumer`, and the `nx.json` defaults

Brief for
[S17.5.1](../F17.5-consumer-checks-in-kiln.md#s1751-take-kilns-cidist-and-ciconsumer-and-the-nxjson-defaults),
at `81e7878`.

## Goal

`nx.json` gains kiln's `verify-consumer` target default, and the release
pipeline page says that `dist-resolve` strips `workspace-ci`, so the consumer
matrices S17.5.2 and S17.5.3 add run through `task ci:consumer` and are never
published.

## Settled

- Most of the story's Build already landed with the cutover (S17.2.1, S17.2.3),
  checked by the lead on 2026-11-14:
  - Entry check: kiln `6da1438` is an ancestor of `origin/feature/v1`
    (`git merge-base --is-ancestor`). Do not run `gh`.
  - `tools/ci/` is gone; `task --list-all` lists `ci:dist:resolve`,
    `ci:dist:verify` and `ci:consumer`; `nx.json`'s `pack` and `verify-dist`
    defaults are kiln's; all seven hand edits in the story's Build step 3 are
    present.
  - `docs/architecture/release-pipeline.md` already names `task ci:dist:resolve`
    and `task ci:dist:verify`, and nothing under `docs/architecture`,
    `docs/guides`, `AGENTS.md` or `README.md` names `tools/ci`.
- So Build steps 1, 2 (except the one key below), 3 and 4 are not repeated. Do
  not rebuild the reference repository and do not run `task kiln:apply`.
- The one key missing is `targetDefaults["verify-consumer"]`. Add it to
  `nx.json` by hand (kiln never rewrites an existing `nx.json`), with the value
  the reference repository holds, keys in the order the other target defaults
  use (`executor`, `dependsOn`, `cache`, `options`), placed after
  `verify-dist`:

  ```json
  "verify-consumer": {
    "executor": "nx:run-commands",
    "dependsOn": ["pack"],
    "cache": false,
    "options": {
      "cwd": "{workspaceRoot}",
      "command": "task ci:consumer -- {projectRoot}"
    }
  }
  ```

- `libs/ng/project.json` and `libs/ng-tailwind/project.json` keep their own
  `verify-consumer` targets, which override the default, until S17.5.2 and
  S17.5.3 replace them. `task ci:smoke` therefore still runs
  `tools/scripts/verify-consumer.mjs`.
- In `docs/architecture/release-pipeline.md`, the `pack` bullet gains, at its
  end: "`dist-resolve` also removes `workspace-ci` from the dist manifest, so a
  library's consumer matrix is not published." Nothing else on the page
  changes.

## Current behaviour

- `nx.json` `targetDefaults` has `pack` and `verify-dist` (kiln's values) and
  no `verify-consumer`.
- `docs/architecture/release-pipeline.md`'s `pack` bullet explains the
  `workspace:` rewrite and does not mention `workspace-ci`.
