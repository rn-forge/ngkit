Reduce overlapping option bookkeeping only after measuring it, and make plugin
resources follow Angular component lifetimes.

## S19.5.1 — Resolve options through one tested path

**State:** Closed (2026-11-18) · **Depends on:** S19.3.2

**Acceptance:**

- Tests pin default/global/input/runtime precedence, empty and shorter arrays,
  override replacement/merge/clear, callback preservation, input immutability
  and independent component instances before changing the caches.
- The decision on array replacement versus element merging is explicit before
  implementation; changed observable behavior gets migration guidance.
- Remove duplicate diff/cache work only when the baseline supports it. Keep
  signal invalidation correct, preserve subclass hooks, and release
  per-instance state on destroy. Do not add a general configuration framework.
- Arrays merge by index at resolution, unchanged (a shorter or empty array does
  not shorten a default); option objects are immutable values; a callback-only
  change is not detected. The `ConfigurerService` doc comment states this
  contract.

Outcome: three same-reference short-circuits cut `diff` calls per unchanged
input change from 26/64/212 to 12/31/105 (table) and 15/37/127 to 7/18/63 (form)
at S/M/L; every other count equals the baseline. Median time could not be
confirmed within +10%: load stayed 20–50 from outside work and over-threshold
cells varied between runs. The owner accepted the change on counts (2026-11-18).

## S19.5.2 — Destroy the table and its deferred work

**State:** Closed (2026-11-18)

**Acceptance:**

- Fixture destruction releases the plugin instance, selection listeners and
  outstanding highlight timers. Explicit `destroy()` followed by Angular
  destruction is safe; rerender does not accumulate listeners.
- Rows with string IDs containing spaces, quotes or selector punctuation are
  highlighted without malformed selectors or matching a different row.
- Preserve vendor access, tree callbacks, selection-linked toolbar behavior and
  lazy-import ordering. Any loader change retains real browser coverage; no
  speculative vendor replacement is included.

## Acceptance

- S19.5.1: Option resolution has one measured owner and preserved precedence.
- S19.5.2: Table resources end with their component and arbitrary IDs work.
