## Tests first

These are checks, not unit tests; there is no failing state to start from,
because the behaviour already holds. Record each result in `## Result`. Run from
the repository root, with `NX_WORKSPACE_ROOT_PATH` unset.

```bash
set -euo pipefail
absent() { local rc=0; grep -rqE "$@" </dev/null || rc=$?; [ "$rc" -eq 1 ]; }
D=docs/specs/epics/E19-ngkit-simplification/_briefs

# precondition: tree clean apart from this brief
git status --short -uall | grep -v "$D/S19.1.1.md" && exit 1 || true

# 1. one rule: AGENTS.md links the Briefs section, inside the kiln block
grep -qF '(docs/specs/_structure.md#briefs)' AGENTS.md
# 2. the brief rule exists once as a heading in the generated structure page
[ "$(grep -c '^### Briefs$' docs/specs/_structure.md)" = 1 ]

# 3. a scratch brief for another open story is excluded and changes nothing
printf '# S19.1.2 scratch\n\nSCRATCHMARKER\n' > "$D/S19.1.2.md"
task docs:generate
git diff --quiet                          # no tracked file changed
task docs:build
absent SCRATCHMARKER .docs-site
absent 'S19[.]1[.]2 scratch' .docs-site
[ ! -e .docs-site/specs/epics/E19-ngkit-simplification/_briefs ]
rm "$D/S19.1.2.md"

# 4. kiln's check rejects a brief whose story does not exist (lint runs it)
fails_with() { local out rc=0; out=$("${@:2}" 2>&1) || rc=$?; [ "$rc" -ne 0 ] && grep -qF -- "$1" <<<"$out"; }
printf '# S99.9.9 scratch\n' > "$D/S99.9.9.md"
fails_with 'which is not a story in E19-ngkit-simplification' task lint
rm "$D/S99.9.9.md"

# 5. the tree is restored
task docs:generate
git status --short -uall | grep -v "$D/S19.1.1.md" && exit 1 || true
```

Behaviour before any change: every line passes (step 4 runs `task lint`, so it
takes minutes). `absent` uses `grep -r` because `.docs-site/` is git-ignored and
`rg` would skip it.
