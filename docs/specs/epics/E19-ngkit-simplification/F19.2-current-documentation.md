## S19.2.1 — Repair inventories and command guidance

**State:** Closed (2026-11-18)

**Acceptance:**

- Root and docs landing pages identify all three publishable libraries;
  inventories link to their owning READMEs instead of duplicating setup.
- Development examples use supported `task` routes. Where a required operation
  lacks a wrapper, record the tooling gap with its owner rather than claiming
  a nonexistent task or recommending forbidden direct commands.
- Descriptions of the consumer matrix, workspace Angular version and published
  peer floor distinguish those facts and agree with their actual owners. The
  F17.4/F17.5 changes update their guidance when they land.

Outcome: landing pages and inventories name all four publishable projects;
command guidance uses `task` verbs or project-scoped `pnpm exec nx`; operations
without a verb are listed as kiln tooling gaps in `docs/guides/development.md`.
Owner addendum (2026-11-18): AGENTS.md release invariants and ADR-0002's
workspace version corrected.

## S19.2.2 — Keep docstrings contractual

**State:** Closed (2026-11-18)

**Acceptance:**

Outcome: four doc comments corrected (`updateOptions`, `TableComponent.render`,
the `UserSettingsService` example, `bootstrap-loader.ts`); the test titles and
packed README links changed in this epic already met the rule.
