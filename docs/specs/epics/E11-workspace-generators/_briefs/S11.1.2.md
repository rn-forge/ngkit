# S11.1.2 — `@rn-forge/ng-plugin:add-bootstrap-table`

Brief for
[S11.1.2](../F11.1-ng-plugin.md#s1112-rn-forgeng-pluginadd-bootstrap-table), at
`d61ad04`.

## Goal

Add the `add-bootstrap-table` generator to `@rn-forge/ng-plugin`
(`tools/ng-plugin`). It adds the three Bootstrap Table dependencies to an
Angular application and, optionally, scaffolds an example standalone component
that renders `rnf-table`.

## Settled

- **Contract:** F11.1's Design: "Decisions" (`add-bootstrap-table` shrinks to
  the three dependencies and an optional example; no extension list), the
  "`add-bootstrap-table`" schema and steps, and "Design defaults" (example
  scaffold is a standalone component only; component prefix is the project's
  `prefix`, falling back to `rnf`). S11.1.2's acceptance.
- **Reuse, don't duplicate:**
    - `readAngularApplication` (`src/utils/angular-project.ts`) validates the
      project and throws the `Angular application` error before any change.
    - `addBootstrapTableDependencies` (`src/utils/bootstrap-table.ts`) adds
      `bootstrap-table`, `jquery` and `jquery-treegrid` with the
      `PEER_DEPENDENCIES` ranges, keeping existing versions. `setup` already
      calls it; leave `setup` as it is.
- **Schema** (`src/generators/add-bootstrap-table/schema.json` and
  `schema.d.ts`, `AddBootstrapTableGeneratorSchema`): `project` (string,
  required, `$default` argv 0, like `setup`), `skipInstall` (boolean,
  `false`), `scaffoldExample` (boolean, `false`). No `packageManager` option:
  the install callback is `installPackagesTask(tree)`.
- **Build target:** the generator never reads or writes the project
  configuration beyond the validation read. No `scripts`, `styles` or `assets`
  entries.
- **Example component** (`scaffoldExample: true`):
    - File:
      `<sourceRoot>/app/bootstrap-table-example/bootstrap-table-example.component.ts`
      (`sourceRoot` falls back to `<root>/src`, as in `setup`). One file:
      inline template, no separate HTML, SCSS or spec.
    - Written as a TypeScript string in the generator module (no template
      directory, so the build's `assets` stay as they are).
    - Content: a standalone component, class `BootstrapTableExampleComponent`,
      selector `<prefix>-bootstrap-table-example`, `imports: [TableComponent]`
      from `@rn-forge/ng-bootstrap`, template
      `<rnf-table [options]="options" />`, and an `options: Partial<TableOptions>`
      with three columns (`id`, `name`, `status`) and three inline rows.
      Follow `apps/ng-demo/src/app/org-chart/org-chart.page.ts` for the imports
      and decorator shape, without the tree-grid options.
    - If the file already exists, leave it untouched (idempotent).
    - It is not added to routes or any other file; the generator logs one
      `logger.info` line naming the file and the selector.
- **Install and format:** `formatFiles(tree)` before returning; return
  `() => installPackagesTask(tree)` unless `skipInstall`, else `undefined`.
- **Registration:** `generators.json` gains `add-bootstrap-table` (factory
  `./src/generators/add-bootstrap-table/generator`, schema
  `./src/generators/add-bootstrap-table/schema.json`, a one-line description).
  `src/index.ts` exports the generator as `addBootstrapTableGenerator` and its
  schema type.
- **README:** `tools/ng-plugin/README.md` gains an `add-bootstrap-table` section
  after `setup`: the usage line
  (`pnpm nx g @rn-forge/ng-plugin:add-bootstrap-table --project=my-app`), the
  options table, and one sentence on the example.
