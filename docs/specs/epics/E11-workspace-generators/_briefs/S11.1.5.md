# S11.1.5 — `@rn-forge/ng-plugin:configure-testing`

Brief for
[S11.1.5](../F11.1-ng-plugin.md#s1115-rn-forgeng-pluginconfigure-testing), at
`e703825`.

## Goal

Add the `configure-testing` generator to `@rn-forge/ng-plugin`
(`tools/ng-plugin`). It sets an Angular application's or library's Vitest
Angular test target to rn-forge's defaults (coverage on, reporters, one
threshold for every metric), patches its `tsconfig.spec.json`, and makes sure
the Vitest dependencies are declared.

## Settled

- **Contract:** F11.1's Design: the "`configure-testing`" schema and steps, and
  "Design defaults" (same thresholds for apps and libraries, default `35`;
  Vitest Angular only). S11.1.5's acceptance.
- **Project check:** `readAngularProject` (`src/utils/angular-project.ts`, added
  in S11.1.4). Its error stands.
- **Test target** (`updateProjectConfiguration`, written only when a value
  changed):
    - No `test` target → add one: `executor: "@nx/angular:unit-test"`,
      `options: { tsConfig: "<root>/tsconfig.spec.json", watch: false }`, then
      the options below.
    - A `test` target with executor `@nx/angular:unit-test` → keep every existing
      option and set the options below.
    - Any other executor → throw an `Error` containing `@nx/angular:unit-test` and
      the executor found, before any change (Vitest Angular only).
    - Options set: `coverage: true`, `coverageReporters` = `reporters` split on
      commas and trimmed (default `text,html,json`), `coverageThresholds` =
      `coverageThreshold` (default `35`) for `statements`, `branches`,
      `functions` and `lines`.
- **`tsconfig.spec.json`** (`<root>/tsconfig.spec.json`):
    - Missing → write it: `extends: "./tsconfig.json"`,
      `compilerOptions: { outDir: "<relative path to workspace>/dist/out-tsc", types: ["vitest/globals"] }`,
      `include: ["src/**/*.ts", "src/**/*.d.ts"]`,
      `exclude: ["**/*.stories.ts", "**/*.stories.js"]`. (`outDir` uses
      `offsetFromRoot(root)` from `@nx/devkit`.)
    - Present → `include` gains `src/**/*.ts` and `src/**/*.d.ts`, `exclude` gains
      the two story patterns, each once, existing entries kept;
      `compilerOptions.types` gains `vitest/globals` once.
- **Dependencies:** root `devDependencies` gain `vitest` `^4.1.12`,
  `@vitest/coverage-v8` `^4.1.12` and `jsdom` `^27.4.0` (constants in
  `src/utils/versions.ts`), keeping existing versions.
- **Install and format:** `formatFiles(tree)`; return
  `() => installPackagesTask(tree)` unless `skipInstall`, else `undefined`.
- **Idempotent:** a second run changes no file.
- **Schema** (`src/generators/configure-testing/schema.json` and `schema.d.ts`,
  `ConfigureTestingGeneratorSchema`): `project` (string, required, `$default`
  argv 0), `coverageThreshold` (number, `35`, `minimum: 0`, `maximum: 100`),
  `reporters` (string, `text,html,json`), `skipInstall` (boolean, `false`).
- **Registration and docs:** `generators.json` gains `configure-testing`;
  `src/index.ts` exports `configureTestingGenerator` and its schema type;
  `tools/ng-plugin/README.md` gains a section after `create-library` (usage
  line, options table, one sentence on what it patches).
- **`create-library` is not changed.** It writes its own coverage settings
  (S11.1.7); folding it onto this generator is not part of this story.

## Tests first

Write these in `generator.spec.ts` (tree from `createTreeWithEmptyWorkspace`; a
library `my-lib` at `libs/my-lib` with an `@nx/angular:package` build, an
`@nx/angular:unit-test` `test` target holding `watch: false` and
`include: ['src/**/*.spec.ts']`, and a `libs/my-lib/tsconfig.spec.json`; an app
`my-app` with an `@angular/build:application` build and no `test` target) before
the generator, with a throwing stub, and confirm each fails:

1. **Coverage threshold:** `--project=my-lib --coverageThreshold=80` → the test
   target's `coverageThresholds` are 80 for all four metrics, `coverage` is
   `true`, `coverageReporters` is `['text', 'html', 'json']`, and `watch` and
   `include` are kept.
1. **Defaults:** without options the thresholds are 35;
   `reporters: 'text-summary, lcov'` gives `['text-summary', 'lcov']`.
1. **Missing test target:** `my-app` gains an `@nx/angular:unit-test` target
   with `tsConfig: 'apps/my-app/tsconfig.spec.json'` and the options above,
   and `apps/my-app/tsconfig.spec.json` is written as settled.
1. **tsconfig.spec.json patched:** an existing file with
   `include: ['src/**/*.spec.ts']` and no `exclude` gains the two includes,
   the two excludes and `vitest/globals`, and keeps its own include.
1. **Dependencies:** root `devDependencies` has the three packages; an existing
   `vitest` `^4.0.0` keeps that version.
1. **Idempotent:** every file's content after a second run equals that after the
   first.
1. **Other executor refused:** a `test` target with `@nx/vitest:test` throws
   with both executor names, and no file changed. A non-Angular project throws
   `readAngularProject`'s error.
1. **skipInstall:** returns `undefined`; without it, returns a function that
   calls `installPackagesTask` (mock it as `setup`'s spec does).
