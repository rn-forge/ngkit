# F4.1 — `@rn-forge/ng/crud` entry point

**Status:** done · **Implemented:** 2026-09-23 (`94faba0`) · **Owner:** ngkit · **Epic:** [E4](index.md)

The presentation-free half of the resource screen: the data-source contract, the list controller, error and conflict handling, file and write helpers, and `standardDataSource()`. What it holds and why is in [Resource screen](../../../architecture/resource-screen.md); this file records the stories that built it.

## Stories

### S4.1.1 — Entry point and contract

**Status:** done (2026-09-23)

**Acceptance:**

- `libs/ng/crud` exists, mirroring `libs/ng/core` (`ng-package.json`, `src/index.ts`, the `tsconfig.base.json` path, the `ng` test include and `coverageInclude`), with the contract types and the `CrudDataSource` interface.
- `./crud` is in `verify-consumer.mjs`'s entry-point matrix.
- `ng-bootstrap/crud` is untouched in this step.
- `pnpm nx run-many -t lint test build -p ng` passes.
- `pnpm nx run ng:verify-consumer` passes.

### S4.1.2 — List controller

**Status:** done (2026-09-23)

**Acceptance:**

- `createCrudList()` on Angular's `rxResource` provides a page-token stack, `orderBy`, declared filters, `pageSize`, selection keyed by `$K`, `reload()` and latest-request-wins.
- Tests pass for: next/previous across three pages; reset on `orderBy` and filter change; a delayed older response never overwriting a newer one; selection surviving a reload only for ids still present; `totalSize` absent versus present.

### S4.1.3 — Errors and conflicts

**Status:** done (2026-09-23)

**Acceptance:**

- `problemToFormErrors(problem, form)` maps RFC 9457 pointers onto form controls, and a 412 becomes a `conflict` state.
- `problemToFormErrors` is hand-rolled under [ADR-0001](../../../adr/ADR-0001.md) exemption 1, after searching npm.
- Tests pass for: nested and array-index pointers; unmatched entries as a form-level error; non-problem bodies ignored; 412 versus other 4xx.

### S4.1.4 — Files and write helpers

**Status:** done (2026-09-23)

**Acceptance:**

- `fileNameFrom()` reads `Content-Disposition` over `content-disposition`, added to `ng` `dependencies`, `allowedNonPeerDependencies` and the root `package.json`.
- The `saveBlob` doc comment records ADR-0001 exemption 3.
- `Idempotency-Key` generation (`crypto.randomUUID()`, one per submit attempt, reused on retry) and optional-method feature detection exist.
- Tests pass for: RFC 8187 `filename*`; the quoted fallback; a missing header; both present (`filename*` wins); key reuse on retry and renewal on a new submit.

### S4.1.5 — `standardDataSource()`

**Status:** done (2026-09-23)

**Acceptance:**

- `standardDataSource()` implements every row of the wire table in [Resource screen](../../../architecture/resource-screen.md#standarddatasource-wire-mapping).
- Tests with `HttpTestingController` pass for: the exact method, URL, params, headers and body of every row; id encoding; array and `undefined` filter params; `ETag` read into `Versioned` and sent back as `If-Match`; the merge-patch content type; `Idempotency-Key` only when given; optional methods absent unless enabled; a 412 or 422 `HttpErrorResponse` reaching the subscriber unchanged; the missing-config error.
